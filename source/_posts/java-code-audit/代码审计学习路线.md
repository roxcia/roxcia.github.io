# 代码审计学习路线

这部分讲解的代码审计主要是围绕java展开，可能会包含部分php和js，不同语言代码审计的思路大致是一样的，熟练掌握java之后的可以考虑审计别的语言

## 基础部分

- 这部分就是学习开发，比较重要的就是**Java语言基础、Java web、tomcat架构、spring及其组件**，可以快速学过一遍，大致有个印象，后面可以根据不同的项目重新加深印象

## Java反序列化

这部分就是要开始学习Java反序列化漏洞，目的是在学习反序列化的过程中学会调试，掌握Java语言特性以及相关学习组件安全漏洞，这部分大概学习的时间会很长，要做好准备，==在这个阶段可以多去打ctf的Java题目==

- 反序列化的基础
- cc链：基础反序列化知识、urldns链、cc1、cc3、cc6、cc2、cc4、cc5、cc7、cc11、cb1(掌握每根链子的不同点以及poc的构造)
- jdk原生反序列化：jdk7u21以及jdk8u20(理解一下原生反序列化和cc链的区别)
- 反序列化利用：rmi、jndi、jrmp以及JEP290
- fastjson反序列化：这是java中非常常见的一个库，也是现在利用手法非常多的一个
  - fastjson基础
  - fastjson1.2.24版本漏洞，以及相关两条利用链
  - fastjson各个版本漏洞，一直到1.2.83
  - **fastjson1.2.83最新版本的漏洞可以深入研究**
  - fastjson不出网的利用(bcel利用链、写文件等，我记得有个公众号一直在做这个挑战可以看看)
  - fastjson原生反序列化漏洞以及高版本绕过
- Jackson反序列化：重点理解和fastjson的区别以及利用手法
- shiro反序列化：这个面试最经常问
  - shiro550和shiro721两条链子以及他们的区别，最好对着源码进行分析
  - shiro有key无链怎么利用以及shiro注入内存马可能出现的问题(面试喜欢问)
- Log4j2、Weblogic和strust2相关漏洞学习
- 表达式注入和模板注入
  - el、spel、ognl几个表达式注入
  - 几个模板注入(重点是FreeMarker 、Thymeleaf )
- hessian反序列化、c3p0反序列化、hibernate反序列化
- 二次反序列化(常见的绕过手法，配合其他链子利用)
- jdbc注入(结合各个数据库，然后还有高版本绕过)
- spring相关组件漏洞，这部分重点要结合jdk高版本来，还要学jdk高版本绕过
- java内存马
  - 通用型内存马
  - tomcat内存马
  - springboot内存马

## 代码审计

- 这里可以先学习php的，先审计一下比较传统的或者老版本的项目，跟着文章一起审计和复现。

- java刚起步我推荐找点简单的项目像华夏erp老版本、若依、的跟着网上先进行审计和复现，然后对发现的漏洞写防御代码

- 后面就是自由发挥，先从开源的项目开始，去github或者gitee找点star多的，版本比较新的项目自己审，大概2-3天一个项目，刚起步少用ai，后面熟练了可以开始用ai或者学用codeql这类的代码审计工具

  反正这个阶段就天天审代码就行，出的洞可以提交cve和cnvd，然后进行批量化


## ai代码审计

- 在这个阶段就可以开始研究代码审计的skills，或者开发一个代码审计的agent架构
- 也可以学习一下用什么提示词可以让ai误判率下降，可以做一个ast抽象数，或者是尝试让agent调用codeql之类的
- 主要就是你们自己探索
